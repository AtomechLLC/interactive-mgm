Replanned · Risk for Score

The score table sets how high you stack

How it works

Three rounds of a block stacker, 28 pieces each. The blocks and the rules never change. Only the score table does: flat, steep, then a jackpot for clearing four lines at once.

Arrow keys move and turn, Space drops. The height lines, clears and points are your own play, and three rounds from one person is a small sample. The walk-through is a script written to chase each table, so it shows the incentive at full strength. The steep table uses the 40, 100, 300, 1,200 values from NES Tetris.

Same Numbers, Different Answers

The maths

Three machines add the same eight numbers. In school maths the order of an addition never matters. A float rounds after every add, so different processors, compilers and GPUs, adding in different orders, land on different last bits.

Computed live with 32-bit floats (Math.fround). Icons: game-icons.net (CC BY 3.0) by Delapouite and Lorc.

One Bit, Two Games

The maths

Two players’ machines run the same physics from the same start and send each other only inputs. Client B adds up the pushes on each ball in the opposite order, as a different processor might.

The simulation is sim.js: 28 soft balls, 60 steps a second, run twice per maths mode.

why determinism is worth it

What Goes Over the Wire

The game

Replication sends what every unit is doing. A deterministic game sends only what every player pressed, and lets each machine work out the rest, which only works if they all get the same bits.

Byte sizes are illustrative: 18 bytes per unit, 6 per player input, 20 updates a second, inputs sent three times for safety. Icons: game-icons.net (CC BY 3.0) by Skoll.

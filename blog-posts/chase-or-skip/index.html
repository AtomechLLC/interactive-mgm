How it works

Run six rooms to the exit. Each room has a reward up a side stair. Space takes the detour, and each one costs 3 seconds. The clock covers three detours. What each reward is worth stays hidden until the end.

Which rewards you chase is your own choice; the worth of each is a number set by this page, and the room order is shuffled on every run of yours. The walk-through's player is a script. After heart pieces in The Legend of Zelda, the Super Mushroom, and room rewards in Hades.

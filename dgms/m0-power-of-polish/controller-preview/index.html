Input to action: puppet architecture

Who drives it

A button push goes to a device, which sends an input signal. The controller is the code that turns input into a command by reading the state of the pawn (the entity in the world), and the resulting actions have side effects: the mechanics. An AI brain issues its commands straight to the controller. Module 5 covers it in full.

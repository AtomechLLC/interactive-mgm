Golden, Silver and Dirt Paths

Three climbers of different skill take the same mountain. Each stretch offers a golden path (short, guarded by something fierce, rich chest), a silver path, and a dirt path (long, safe, coins only). Close a path and see who stops moving.

The mountain each climber takes the hardest open path within their skill

Ashuras (Entry 1): there must be branching routes, a golden path (high skill, high reward), a silver path and a dirt path (safe, slow), so different players can all progress. In this toy model a climber clears a path when their skill is at least its difficulty, and clearing a golden or silver path raises their skill by one.

Every option has a counter

Thrustbeats a backstep (long reach)loses to a sidestep (narrow)
Sweepbeats a sidestep (wide arc)loses to a backstep (short reach)
Blockcheap against thrustsdrains stamina against sweeps
Dodgesafe against everythingbut the attacker resets first
Quickstepthe highest rewardonly if you read the attack

Dodge stays a universal but weaker answer. The best answers are situational, so players have to read each other. That’s the mind game.

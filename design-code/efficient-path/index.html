3 · Align incentives with the fun

Players will optimize the fun out of a game

Two ways to earn XP and ten players free to choose. Watch where they stand before and after one retune.

The principle

If you get alignment wrong, nothing else matters. Players will optimize the fun out of a game if you let them, so make the efficient path the fun path. You can’t make a rule against following incentives.

5 · Be clear before you’re clever

Spend visual intensity only on what matters

One raid pull, drawn twice. The warning lasts 1.2 seconds both times; only the brightness of everything else changes.

The principle

Clarity is the foundation of everything else. Spend visual intensity only on what matters; desaturate and quiet the rest. Power the player can’t see is wasted power, and so is a warning.
